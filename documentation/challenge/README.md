# Challenge Development

This section records work performed during the official challenge development period.

It is separate from the [pre-challenge baseline](../baseline/README.md). A change belongs here only after it is implemented during that period. Planned work stays labeled as planned until then.

## Documents

- [Development plan](development-plan.md) — intended work, not completed work
- [Contribution log](contribution-log.md) — work actually performed during the challenge period
- [Validation](validation.md) — tests and results, without invented outcomes
- [Challenge evidence](challenge-evidence/README.md) — files produced during challenge-period development
