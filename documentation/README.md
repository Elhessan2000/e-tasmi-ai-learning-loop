# e-Tasmi AI Learning Loop — Documentation

This folder is the documentation set for the e-Tasmi AI Learning Loop entry in the AI Challenge in Service of Islamic Content 2026.

It separates the documented starting state of the existing project from work that is planned or performed during the official challenge development period. Challenge implementation is not described as complete in these documents.

## Baseline documentation

[baseline/](baseline/README.md) records the pre-challenge system: what already existed, how that state is identified in Git, and the evidence still to be collected.

## Challenge development documentation

[challenge/](challenge/README.md) is reserved for work performed during the official challenge development period. Planned work is labeled as planned until it is implemented and recorded.

## Setup documentation

[setup/](setup/README.md) describes how to run the isolated local challenge environment.

## Final submission documentation

[final/](final/README.md) holds templates for the final report, submission checklist, and demo material. Those documents are not filled with unsupported claims.
