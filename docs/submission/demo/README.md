# Demo

This folder is for final demo material. No demo video is stored here, and no video is claimed to exist.

## Demo objective

Show the implemented learning loop: an instructor decision, a published student result, a linked Practice Again attempt, and a reference-unavailable review that does not invent Qur'an text.

## Demo flow

1. Sign in as the challenge instructor and open Evaluations.
2. Open a recitation whose findings are already verified. Show one accepted or edited finding and the publication gate: a pending finding cannot be published.
3. Sign in as the challenge student and open the published result. Show the score, the instructor feedback, and the verified focus. An empty focus says there is nothing extra to practise.
4. Choose Practice Again. Submit on the same session. The new recitation stores the parent id and the next attempt number on that enrollment.
5. Open a recitation whose analysis status is `REFERENCE_UNAVAILABLE`. Show the card “Trusted reference unavailable”, including the sentence that no Qur'an text was generated. Save a manual score. The student result for that review shows the empty focus and does not show the reference reason.

## Screens to show

- Instructor evaluations, including the verification actions and the reference-unavailable card.
- Student recitation result.
- Student recitations studio opened with `practice` set to the published recitation.

## Challenge contribution to demonstrate

Demonstrate trusted Quranpedia comparison, instructor verification, the published student focus, Practice Again lineage, and the reference-unavailable safe-failure card. ElevenLabs Scribe v2 is the active speech-to-text provider. Do not claim a progress-formula change.
