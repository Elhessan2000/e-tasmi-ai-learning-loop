# Original evidence source

The screenshots in this documentation package were copied from the project folder:

`Evidence e-tasmi`

That folder is the source of truth. It is a directory of PNG files, not an archive. It was inspected in place and was not renamed, reorganized, extracted over, or edited.

Copies used for this booklet live under `docs/evidence/screenshots/`. Where a PDF figure shows only part of a tall or mostly empty screen, the full copy is stored beside it. The Cloudinary copy is redacted: the account email is covered and marked `email redacted`. The original Cloudinary screenshot remains unchanged in `Evidence e-tasmi`.
