# e-Tasmi tools and services evidence

This folder is the challenge documentation package for the tools, services, APIs, and platforms used to build and validate the e-Tasmi AI Learning Loop. It follows the existing `docs/` structure. It does not replace `docs/challenge/challenge-evidence/`, which is reserved for challenge-period behaviour evidence.

## Contents

| Path | What it is |
|---|---|
| `e-Tasmi_Tools_Services_Licensing_Documentation.pdf` | Curated evidence booklet |
| `evidence-index.md` | Register of every supplied screenshot |
| `screenshots/` | Copies organized by service |
| `source/README.md` | Where the original evidence lives |

## Where the originals came from

The originals are the eleven PNG files in `Evidence e-tasmi` at the project root. That folder was left untouched. Nothing here was copied from production, and no credentials were added.

## What the PDF contains

Eight pages: cover, evidence method, AI services, Qur'an sources, development toolchain, hosting and media, licensing register, and references. Statements are limited to the screenshots, project records, and source code that was checked. Pricing is stated only where a screenshot or the official page shown in a screenshot supports it.

## Secrets

No credentials, API keys, passwords, or sensitive beneficiary data are included in this evidence package.
