# Pre-Challenge Baseline Evidence

## Purpose

This directory is reserved for supporting evidence used to establish the state of e-Tasmi before the official challenge development period.

Evidence is added only when it has actually been collected. This folder does not currently hold separate evidence files beyond this index. The categories below point to documentation that already exists elsewhere in the baseline set.

## Evidence Categories

| Category | Examples | Status |
|---|---|---|
| Git evidence | Baseline commit and tag | Documented |
| System evidence | Existing workflows and interface | Documented |
| Technical evidence | Versions and environment | Documented |
| Database evidence | Schema/setup information | Documented |
| Configuration evidence | Non-secret configuration facts | Partially documented |
| Rights evidence | Licences, API terms, permissions | To be verified |
| Privacy evidence | Public repository/data review | To be verified |

“Documented” means the baseline documents already record that category. It does not mean a separate file has been placed in this folder, and it does not mean a review checklist is complete.

## Planned Supporting Evidence

The following may be added later, and only when actually collected:

- Git verification output
- system and version information
- schema evidence
- configuration verification
- additional baseline screenshots
- licence and terms references
- ownership and permission records

Do not add placeholders in place of collected evidence.

## Security

This directory must never contain:

- secrets
- API keys
- passwords
- access tokens
- real production database dumps
- private user records
- unauthorized private audio

## Boundary

This directory supports the documentation of the pre-challenge baseline. It does not contain challenge-period implementation evidence.
