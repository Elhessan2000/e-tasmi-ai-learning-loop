## Removed

Earlier screenshots of the login page, student dashboard, Qur'an Library, recitation result, and instructor evaluation were removed because they showed a real account name, a personal email address, or another person's display name.

These views are not republished, because a faithful recapture would require a real submission or a real roster:

- student result / evaluation report
- instructor AI analysis panel
- completed instructor review
- a specific Qur'an verse reader screen

## Privacy

Do not add a screenshot that shows a real name, email, phone number, avatar of a real person, payment receipt, or audio belonging to a real learner.
