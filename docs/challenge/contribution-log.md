## Challenge progression

The public release records three days of challenge work. The table below is the evidence. It is not a second log.

**Day 1 — Foundation.** The challenge environment was isolated. A session stores a structured Qur'an passage. Comparison uses a trusted reference, Arabic normalization, and deterministic finding types. Analysis and findings are stored. AI explains those findings. It does not invent the mushaf text. Missing input fails safely.

**Day 2 — Verification and automation.** The instructor accepts, edits, rejects, or adds each finding. Unpublished findings do not reach the learner. A published review becomes Verified Learning Focus, and Practice Again starts the next attempt. Analysis runs in the background, with job recovery. Speech-to-text is ElevenLabs Scribe v2. The comparison text is Quranpedia Hafs.

**Day 3 — Public release.** The learner and instructor experience, validation, and documentation under `docs/` were finished for the loop as it stood on 3 Oct 2026. Public screenshots use synthetic accounts. Private images, the packaged baseline export, and the competition presentation stay out of this repository.

**5 Oct 2026 — Student Progress.** The existing Learning Snapshot stays. Published Recitation History, Latest Verified Focus, and a comparison with the previous published attempt were added on the same page. No new database table was added. Commit `d4bb3ea`.

The rows below were written as the work landed. Earlier status text said "not pushed". That text is retired. The Commit column stays blank where a hash was not recorded at the time. It is not backfilled with a guess. Every row through 3 Oct 2026 is on `master`. The 5 Oct 2026 Student Progress row names commit `d4bb3ea`.
